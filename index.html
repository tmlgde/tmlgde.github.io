LockFit – application mobile de musculation

LockFit permet de suivre ses entraînements, visualiser sa progression et sécuriser ses données grâce à une authentification multi-facteurs. Le projet est déployé sur Render (backend + frontend).

Stack technique

Frontend (mobile) : React Native (Expo)

Backend (API REST) : NestJS + Prisma

Base de données : PostgreSQL

Hébergement : Render (back + front)
